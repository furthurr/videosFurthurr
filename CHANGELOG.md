# Historial de cambios

## [v0.1.0] - 2026-10-29

### Funcionalidades

- Biblioteca pública de videos WebM con búsqueda, etiquetas y reproductor adaptable.
- Administración privada con GitHub y Supabase para crear, editar y publicar videos.
- Enlaces compartibles y generación de páginas con metadatos sociales.
- Identidad visual e iconos adaptados a navegadores y dispositivos.

### Infraestructura y verificación

- Migraciones, políticas de acceso y función de administración de Supabase.
- Flujo de GitHub Actions para verificar y publicar el sitio en GitHub Pages.
- Pruebas de lógica, políticas y navegador para los flujos principales.
